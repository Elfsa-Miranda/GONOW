# GoNow deterministic OpenAPI to Dart generator

This repository-owned generator uses only the locked Python standard library
and the locked Dart SDK formatter. It verifies the raw OpenAPI SHA-256 and a
frozen backward-compatibility surface before rendering the typed Dart client.
Generated files are written atomically.

```powershell
python .\tool\openapi-generator\generate.py --write --dart-executable <locked-dart.exe>
python .\tool\openapi-generator\generate.py --check --dart-executable <locked-dart.exe>
```

`--check` exits non-zero for a spec digest drift, a removed operation/response,
a removed required schema field, stale generated bytes, or an unexpected
generated file. The tool never reads credentials and never performs network or
production operations.
